# CS 340 Portfolio Reflection

### How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

I write programs that are maintainable, readable, and adaptable by organizing code into functions and modules that have specific purposes. In Project One, I created a CRUD Python module to perform create, read, update, 
and delete operations on a MongoDB database. In Project Two, I reused the module to connect the dashboard to the database. This allowed me to use the same database operations without having to rewrite them in the dashboard 
code. Keeping the database operations separate also made it easier to make changes without affecting the rest of the program. I could reuse this module in future projects that require a database, although I might need to
adjust the connection settings and queries to meet the project's requirements.

### How do you approach a problem as a computer scientist? Consider how you approached the database or dashboard requirements that Grazioso Salvare requested. How did your approach to this project differ from previous assignments in other courses? What techniques or strategies would you use in the future to create databases to meet other client requests?

I approach problems by breaking them into smaller tasks and working through each requirement. For the Grazioso Salvare project, I needed to make sure the database could return the correct animal records based on the 
requested search criteria and that the dashboard displayed the results in the data table and map. I worked on the database queries and dashboard functionality and tested them to make sure they worked as expected. 
This project was different from some of my previous assignments because I had to bring together a database, a Python module, and a dashboard instead of focusing on one part of a program at a time. In future projects, I 
would start by reviewing the client's requirements and identifying the information they need to store and retrieve. I would then plan the database structure, create queries that meet their needs, and test the results 
to make sure the database and application work correctly.

### What do computer scientists do, and why does it matter? How would your work on this type of project help a company, like Grazioso Salvare, to do their work better?

Computer scientists solve problems by developing software and systems that help people work with information and complete tasks more efficiently. This matters because a well-designed program can reduce the amount of time
people spend doing tasks manually and make information easier to use. The Grazioso Salvare dashboard allows users to filter animal records and view the results in a table and on a map. Instead of searching through the
database manually, users can narrow down the records to find animals that match their criteria. This could help Grazioso Salvare find relevant animal information more efficiently and make better use of its data when 
determining which animals may be suitable for its needs.
